# TRACE — 흔적을 쫓는 사람들

데이터 리터러시와 공정한 협업을 주제로 한 GBL(Game-Based Learning) 참가자용 웹페이지입니다.

## 열기

`outputs/trace-project.html`을 브라우저로 열면 미션 로비가 시작됩니다. 네 개의 미션 카드를 누르면 각 활동 전용 페이지로 이동합니다.

## 구성

- 스포츠 데이터: 기록·상황·반대 증거를 바탕으로 경기 결과 예측
- 금융 리스크: 가격 그래프·공시·뉴스를 시간순으로 검증
- 미디어 검증: 원출처·독립 자료를 활용한 주장 판정
- 물류 추적: 시간·거리·제약 조건을 고려한 최적 경로 설계
